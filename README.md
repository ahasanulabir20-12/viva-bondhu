# ভাইভা বন্ধু — A + B + C Category

**Brand:** Ahasanul  
**Type:** Static HTML/CSS/JavaScript website  
**Purpose:** বাংলাদেশি Electrician A + B + C Category viva preparation

## Project structure

- `index.html` — main website
- `assets/styles.css` — responsive design and animations
- `assets/app.js` — questions, quiz, mock viva and interactions
- `assets/data.js` — A/B/C question and gallery data
- `assets/images/` — all supplied viva images and diagrams
- `assets/fonts/` — local Noto Sans Bengali font

## Deploy on Vercel

This website needs no build command and no environment variables.

1. Upload all files to a GitHub repository. Keep `index.html` at the repository root.
2. Import the repository in Vercel.
3. Set **Framework Preset** to **Other**.
4. Leave **Build Command**, **Install Command**, and **Output Directory** blank.
5. Click **Deploy**.

## Important

Do not rename or move the `assets` folder unless all paths in `index.html` are updated. The site is already optimized for desktop and mobile.
